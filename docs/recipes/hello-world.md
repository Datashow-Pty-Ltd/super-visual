# Recipe: deploy Hello World

Hello World is the smallest complete Super Visual project. It displays a
searchable catalog of a Power BI semantic model, proving that the React page is
receiving live governed metadata. Users select one workspace and one semantic
model.

## What you need

- Node.js 22.12 or newer and `npm ci` completed.
- Azure CLI signed in to the tenant used by Fabric.
- A Fabric-capacity workspace containing a semantic model you can read.
- Permission to publish a report in that workspace.

If you do not know the immutable IDs, list the workspaces and then inspect the
chosen workspace:

```bash
npx supervisual deploy workspaces --json
npx supervisual deploy discover \
  --workspace-id <workspace-guid> \
  --workspace-name "<expected workspace name>" \
  --json
```

## 1. Initialize the report

```bash
npx supervisual init hello-world-report \
  --template hello-world \
  --workspace-id <workspace-guid> \
  --workspace-name "<expected workspace name>" \
  --semantic-model-id <semantic-model-guid> \
  --report-name "Super Visual Hello World"
```

The IDs are stored in ignored local project state. The semantic-model ID is the
ordinary Power BI semantic model selected for the report—not an ID generated by
Super Visual.

## 2. Test the live React page locally

```bash
cd hello-world-report
npx supervisual dev --open
```

The local Node.js gateway reads the selected semantic model and gives the React
page only the governed catalog rows it needs. The browser receives no Fabric
token and no arbitrary DAX facility.

For a bounded browser and interaction check, run:

```bash
npx supervisual preview test --json
```

Search for a known table, column, or measure. The summary cards and table are
ordered by the semantic hierarchy: model, tables, columns, measures,
hierarchies, hierarchy levels, relationships, and parameters.

## 3. Publish the report

```bash
npx supervisual publish
```

`publish` packages and verifies the project, displays the exact workspace,
operations, and content-derived plan ID, then asks you to type that plan ID.
Press Enter to cancel without changing Fabric.

After publication, open **Super Visual Hello World** in Power BI Service and
confirm that the same catalog renders and remains searchable. A later update
requires a fresh plan; use `--allow-updates --backup <directory>` only when you
intend to replace the existing report deployment.
